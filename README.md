# student-performance-lifestyle-dashboard
📊 Student Performance & Lifestyle Analytics Dashboard
🧩 Project Objective
Analyze how students’ study habits, screen time, and sleep impact academic performance using data visualization.
📁 Dataset
The dataset contains:
Student ID
Department
Study Hours
Screen Time
Sleep Hours
Marks
🔍 Analysis Performed
Study habits trend analysis
Lifestyle time distribution
Department-wise performance comparison
Performance distribution
Relationship between lifestyle factors and marks
📈 Tools & Libraries
Python
Pandas
Matplotlib
🧠 Key Insights
Balanced study and sleep hours correlate with better performance
Excessive screen time negatively impacts marks
Some departments consistently outperform others
📌 Conclusion
This project demonstrates how lifestyle choices significantly influence academic outcomes and how data visualization helps derive meaningful insights.
